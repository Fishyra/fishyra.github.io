GETTING STARTED / ALPHA 0.3

先安装，再出发。

本指南对应 0.3.0-alpha.2。启动器仍在测试中，更新前请备份重要配置、游戏与服务器存档。

选择对应的安装包

  • macOS：分别提供 Apple Silicon（M 系列芯片）与 Intel（x86_64）DMG，按芯片选择。Intel 包声明需要 macOS 11 或更高版本，目前仅完成交叉装配与架构检查，尚未原生实测。打开后将 OchreCL.app 拖入 Applications。应用尚未进行 Apple 开发者签名与公证；若遇到安全提示，请确认文件来自本页提供的下载地址，并按系统安全设置处理。不提供 32 位 macOS x86 包。
  • Windows：下载 x64 ZIP，完整解压到本地目录，运行 OchreCL.exe。保留同目录的 app 与 runtime，不要只复制 EXE。当前建议先在真实 Windows 环境测试。
  • Linux：下载 x64 TAR.GZ，完整解压后在图形桌面运行 ./OchreCL。需要 glibc x86_64 与 GTK 3；不适用于 Alpine/musl 或 ARM。

所有安装包均内置启动器运行所需的 Java 和 JavaFX。Minecraft 本身可能需要另一版本的 Java，请根据游戏实例要求选择。Windows、Linux 包已完成打包完整性检查，尚未完成原生系统实测。

官网按钮直接下载 GitHub 托管的安装包，无需提取码，也不用先打开发行页面。可使用官网提供的 SHA-256 校验和确认文件完整性。

启动你的第一个游戏

  1. 首次启动时按引导设置外观与主题色。
  2. 在账号页面添加账号，再从下载页面选择游戏版本及所需加载器。
  3. 完成安装后，在主页选择游戏实例，点击「启动游戏」。

游戏启动进度与实时日志会在弹窗显示。选择「后台启动」可以收起进度；任务完成前可通过悬浮球返回。

管理本地服务器

  1. 从下载页面的「服务器」入口选择主流核心，或搜索其他服务器核心。
  2. 选择游戏版本与构建，填写服务器名称、端口、内存等配置，阅读并自行决定是否接受 Minecraft EULA，再部署服务器。
  3. 在服务器面板查看控制台、运行状态，管理玩家、附加项和备份。

SFTP 和 OpenFrp 为可选功能。工具未安装时会提示下载安装；OpenFrp 需要你自己的账号和相应隧道配置，具体可用节点及配额以服务商为准。

悬浮球与后台任务

右键悬浮球可展开任务菜单，查看运行中的游戏、服务器与安装任务，点击跳转。安装时选择「静默安装」可收起进度弹窗；下载箭头表示安装任务，轨道粒子动画表示游戏启动中。

让外观跟随你的背景

进入设置的外观页面，选择「沉浸式透明（实验）」并选取背景图片。组件显示半透明毛玻璃，主题色自动从背景取色，文字根据壁纸整体明暗调整。可以直接使用已选或内置图片，退出透明模式会还原原背景。也可以使用必应壁纸。其他主题模式保留独立的主题色设置。

游戏设置与可选桥接

主页仅对实际 Minecraft 26.x 实例显示「操作游戏」。组件需要逐实例同意安装，重启游戏后生效，不要求 Fabric/Forge，也不改写游戏 JAR。目前已实测原版 26.2，可读取设置、调整声音与视频选项；其他 26.x 版本仍需验证。脚本工作区现可执行英文 Øchre Script；使用前需安装/修复新版桥接并重启游戏。移动、攻击、背包等新接口尚未完成世界内端到端验证。

开始使用 Øchre Script

在 26.x 游戏的「操作游戏 → 脚本」中新建或导入 .ochre 文件。导入、选中与保存不会执行代码；勾选本次所需权限，再点击「运行脚本」。设置更改会保存，关闭工作区会停止脚本。下面例子只需 game.read 权限。

int count = 3;
for (int i = 0; i < count; i++) {
    print(i);
    sleep(200ms);
}
print(game.language);

使用英文关键字与单位、大括号和分号。支持类型变量、if/else、while、for 和列表遍历。编辑器支持括号/引号配对、缩进、行号、注释、复制/移动行、查找和撤销重做。

当前不含语法着色、符号补全、断点或自定义函数；walk_to 寻路和精确手臂定位会明确报能力不可用。游戏控制接口仍是实验功能，需要在测试世界进一步验证；脚本不绕过服务器权限。

通过启动器更新

0.3.0-alpha.1 已带更新引导器，可直接检查本次更新；更早版本需先完整安装新版。之后在「关于 → 启动器更新」检查新版，从本项目 GitHub 直接下载并校验更新包，确认后于下次启动加载；可以回退到内置版本。若 Java、JavaFX 或原生依赖变化，请下载安装完整包。不要将更新 JAR 当成安装程序。

服务器地址与导入

服务器页顶部可导入已有目录，原目录保留。部署与导入显示分步骤进度。地址下拉菜单区分本地、局域网及已配置穿透/公网地址；不会把未验证的公网入站显示成已连通。「网络检测」与异常应急为独立操作，异常监测不等于 DDoS 防护。

常见问题

微软账号为什么需要额外配置？

ØchreCL 的独立 Microsoft 应用 Client ID 尚需配置。设置中提供配置入口与注册说明；不要将密码或 Client Secret 填入 Client ID。公开版本的微软登录能力取决于有效的应用注册与相关授权。

Windows 或 Linux 无法打开怎么办？

先确认系统架构和安装包一致，并已完整解压。Linux 检查 GTK 3 和图形桌面。请记录系统版本、错误提示与日志后提交问题。不要在曾导致整机失去响应的兼容层中反复启动。

在哪里反馈问题？

请前往 GitHub Issues，附系统版本、启动器版本、复现步骤和已隐藏账号信息的日志。不要上传密码、令牌或完整个人数据目录。

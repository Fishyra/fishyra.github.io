示例：从原木到木镐

下载木镐脚本（.ochre）。在单人生存世界的坚实地面上开始，给背包和快捷栏留出空位。在脚本管理中导入文件，检查语法后运行。已在 Minecraft 26.2 的 Fabric 环境验证。

  • 先用背包里已有的木材。需要时搜索 16 格内已加载的树干，支持橡木、云杉、白桦、丛林木、金合欢、深色橡木、红树、樱花、苍白橡木及绯红和诡异菌柄。不同木板可以混用。
  • 按背包里实际捡到的数量补采。掉落物落下悬崖后，脚本会尝试从原树或附近另一处树干补足材料。没有可达树干时，到「输出与错误」查看采集进度和材料缺口。
  • 材料齐备后制作工作台、木棍和木镐。完成时会检查背包，放下的工作台留在世界里。

语法与单位

关键字、函数名与单位为英文，区分大小写。字符串与注释可以包含中文。每条语句以分号结尾，代码块使用大括号。只使用双引号字符串；// 与 # 开始行注释。

类型：int、float、bool、string、Player、Vec3、List、Record。int 为有界整数，float 为有限数值；未赋值变量不能读取。none 表示无目标或空槽。Record 用“变量.字段”读取成员；先赋给变量再访问函数结果的字段。List 目前使用 for (item in list) 遍历及 list.length，不提供数组下标或任意 Java 调用。自定义函数、托管模块和检查点见下节。

时间 s / ms，距离 blocks，角度 deg；单位不能混用。sleep(1s) 合法，sleep(1) 不合法。函数可以使用位置参数或命名参数；位置参数必须在命名参数之前，不能重复赋同一个参数。所有动作默认同步等待。

int count = 3;
float speed = 0.5;
bool ready = true;
string message = "Hello";
for (int i = 0; i < count; i++) {
    print(i);
    sleep(200ms);
}
Record snapshot = player.snapshot();
if (snapshot.in_world) {
    print(snapshot.position);
}
for (event in player.events()) { print(event); }

支持 if / else、while、计数 for、遍历 for、++ / --、赋值与数值运算、比较、!、&&、||；逻辑运算短路。不能覆盖 game/world/player/settings/script/input/chat 等保留名称。

读取属性

除 script.running 与 script_repeat_count 外，以下读取使用 game.read 能力。没有世界或游戏版本缺少能力时会明确失败，不会编造 0 或 false。

属性返回内容
game.language当前语言字符串，如 en_us。
world.day_time / world.game_time当前世界时钟数值，只读；不代表拥有设置服务器时间的权限。
player.position / player.rotation / player.healthposition 含 x/y/z；rotation 含 yaw/pitch；health 为真实血量，只读。
player.inventory.slotsList，空格为 none，非空格包含 slot、id、count。
player.effects最多 64 个药水效果记录：id、duration（游戏 tick）、amplifier（等级从 0 起算）。
player.recipes最多前 64 个已解锁配方的 display_id 记录，供 craft 使用。
player.statesRecord：swimming、sprinting、crouching、underwater、fallflying、on_ground、flying、may_fly。读取能力不意味着可写。
player.hotbar当前快捷栏索引 0..8。
script.running当前运行中为 true，循环仍受预算限制；无需 game.read。
script_repeat_count只读，本次运行的失败重试次数配置。不是当前循环计数，范围 0..100。
player.inputs游戏动作输入 Record：forward、backward、left、right、jump、sneak、sprint、attack、use。读取当前游戏绑定，支持改键；菜单/暂停/世界外为 false，不代表实际已经移动或攻击。
player.states.jumping原生 isJumping 跳跃输入状态；不是“空中”判定，可能按住跳跃时持续为 true。实际起跳应结合 on_ground 的变化、正向 y 位移及排除飞行/游泳。player.snapshot() 也含 jumping 与 inputs。
player.vitals生命与环境 Record：health、max_health、absorption、armor、food、saturation、air、alive、on_fire、in_water、in_lava、freezing、frozen_ticks、fall_distance、passenger、xp_level、xp_progress、using_item、use_ticks、using_item_id、use_animation。
player.container当前菜单 Record：open（外部容器）、id、type、token、slot_count。自身背包也是有效菜单；token 随世界/菜单实例变化。
game.screenUI Record：open、type、paused、in_world；世界外也可读取。
game.observation_status被动检测诊断 Record：hooks（已匹配的挂钩名称，以逗号分隔）、sampling_hz、retained_events、event_page。挂钩缺失意味着该版本能力不完整；hooks 存在不代表事件必然发生。

方块、生物与村民交易

这些接口需要 0.3.0-alpha.9 开发版与对应游戏桥接。更新启动器后重新启动 Minecraft。

  • 按按钮、开门或插末影之眼时，先用 world.block() 取得方块记录。调用 player.use_block() 或 player.use_item_on_block() 后，再读取方块状态确认结果。使用末影之眼时，可指定 item="minecraft:ender_eye" 核对手持物品。查看插眼示例
  • 用 player.use_entity() 对指定生物执行交互，例如给牛挤奶。朝当前方向投掷物品可使用 player.use_item()。查看生物交互示例
  • 用 player.open_trade() 打开交易界面，查看报价中的两项成本、产物和售罄状态，再用 player.trade() 完成一笔交易。每次成交后重新用 player.trade_offers() 读取报价。查看兑换末影珍珠示例

方块、输入与事件记录

方块 Record 含 position、world、id、state、air、solid、replaceable、loaded、distance；准星查询额外有 face。solid 只是阻挡移动的提示，不是完整碰撞形状。优先把原 Record 传给 mine/place/lock，让运行器检查世界会话和目标类型。放置坐标是支撑格，不是目的格。已观察的客户端变化仍可能被多人服务器纠正。

事件 type 包括 world_enter、world_leave、move、hotbar、held_item、state、overflow，以及下表新增事件；非 overflow 事件含 sequence/time。move 含 x/y/z、position、distance、dx/dy/dz、world；hotbar 含 from_slot/to_slot/item；held_item 含 from_item/item/count；state 含 name/from/to。不同类型字段不同，不要直接读取不存在的字段。每个脚本有独立游标，首次调用可能读到桥接保留的近期事件。

事件字段与依据
lookyaw/pitch、from_yaw/from_pitch；采样旋转变化。
input_changename/from/to；可重绑游戏动作输入变化。
input_press / input_releasedevice、code、name、evidence=sampled_input；focused 游戏窗口物理输入，短促输入可能遗漏。
mouse_move / mouse_scrolldx/dy；move 还有 x/y 窗口位置。聚合本采样区间真实鼠标回调，失焦不监听其他应用。
mouse_buttonbutton、action（0释放/1按下/2重复）；游戏窗口回调。
screen_open / screen_closescreen_type、open、paused、in_world；采样 UI 变化。
container_open / container_closecontainer_type、id、token、slot_count、open；外部菜单变化。
vital_changename/from/to；生命、食物、空气、经验、火焰/水/熔岩/冻结/摔落等状态采样变化。

按键别名：A..Z、0..9、SPACE、SHIFT、CONTROL、ALT、ENTER、ESCAPE、TAB、BACKSPACE、DELETE、LEFT、RIGHT、UP、DOWN、HOME、END。modifiers 为掩码：Shift=1、Control=2、Alt=4、Super=8，可相加。它们只作用于游戏，不是桌面自动化。原始输入权限可以操作聊天与菜单，但不会提升服务器权限。

函数、模块与任务检查点

使用 function name(arg1, arg2) { return value; } 定义函数，可以提前调用，支持位置/命名参数。参数无类型标注，最多 16 个，必须全部提供。没有 return 时返回 none；return 可从循环中退出。局部变量隔离，可访问主脚本已有的全局变量；递归调用最多 16 层，仍受总运行预算约束。

function describe(value) {
    print("Observed:", value);
    return value;
}
print(describe(3));

把公共函数另存为脚本库中的 common.ochre，在主脚本顶部写 import "common.ochre";。模块只允许函数声明和进一步导入，不允许顶层执行语句。解析、合并和所需权限检查均发生在运行前；未调用的函数也参与授权。名字冲突、循环导入、路径穿越均报错。模块名须为 ASCII 字母/数字/下划线开头，后续允许点、空格、连字符，后缀 .ochre；只能读取托管脚本库的直接普通文件。最多 8 层导入、16 个模块，合并源码最多 64 KiB 字符。

// common.ochre
function holding_sword() {
    return player.item_is("minecraft:swords");
}
// Separate main.ochre file:
import "common.ochre";
if (holding_sword()) { print("Sword ready"); }
int stage = task.load("stage", default=0);
print("Saved stage:", stage);
task.save("stage", stage + 1);

检查点只保存数据。继续任务时，应自行重新检查世界、目标、容器和材料；不能把上次运行的 token、世界会话或目标当作仍有效。storage.read 与 storage.write 为单独授权能力。

授权、暂停与继续

默认逐次授权：完整解析后列出所需能力，勾选全部后才开始。未执行分支也会参与权限检查。开启“自动授予全部所需权限”只授权启动器能力，不会获得 OP、飞行许可或生成物品的权利。游戏内授权勾选与启动器使用同一次待运行请求；选择取消不执行脚本。

世界控制遇到菜单会暂停，询问是否退出界面继续；手动回到游戏画面也能恢复。确认只针对当前界面和世界，界面变化会拒绝旧确认。悬浮球有“继续”和“停止”；等待确认不计入动作超时。刻意执行 input.*、读取、设置修改和合成时保留原有 UI 上下文。

停止会释放本脚本的临时输入；已经发送的聊天、已保存设置和已发生的世界变化不会撤回。游戏线程冻结时要等它恢复才能处理释放。失败重试可能重复已经产生的效果，请谨慎选择。

错误与运行限制

错误附带原始行列。未知参数、单位不匹配、无目标、超距、遮挡、区块未加载或权限不足会明确失败。没有文字输入控件是正常 not_inserted 结果，不报错。未处理的按键会报错。寻路和手臂定位入口的限制见各自条目。

“设置 → 脚本”可选择停止、跳过、持续重试、按 script_repeat_count 重试（0..100 次额外尝试），每次重试间隔 250ms。权限拒绝、取消、预算耗尽等不会被重试绕过。反复失败且游戏尚未进入世界时，悬浮球会显示三角警告。

每次运行最多约 10 分钟、200000 条解释器指令；源文件 64 KiB 字符、20000 token、80 层解析嵌套；单个宿主约 50 次桥接请求/秒；输出最多 1000 行。每个实例同时一个运行。检查点仅访问实例专属托管 JSON，模块仅读取脚本库；脚本不能访问任意文件、进程、网络或反射。当前能力不是完整的自动通关机器人。

编辑器操作

支持括号/引号自动配对、成对退格、缩进、选择包裹。Tab / Shift+Tab 缩进；⌘/Ctrl+/ 注释；⌘/Ctrl+D 复制行；Alt+↑/↓ 移动行；⌘/Ctrl+F 查找；F3 / Shift+F3 切换匹配；系统撤销重做。

长代码行自动折行，不改变源码与报错行号。列表长文件名省略显示、悬停查看全名。可导入、重命名、删除；删除移入本地脚本回收目录。同名导入加编号，不覆盖旧文件。主界面与实例管理均可在独立窗口编辑。当前尚无语法着色、符号补全或断点调试。

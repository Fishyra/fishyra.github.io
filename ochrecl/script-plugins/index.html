ØchreCL
脚本帮助下载启动器

ØCHRE SCRIPT / PLUGINS

给脚本多几个帮手。

这里的插件是可读、可修改的 .ochre 函数库，供其他脚本调用。首批模块支持 ØchreCL 0.3.0-alpha.6；读取游戏数据需要已连接的游戏桥接。

怎么安装

支持插件目录的启动器可在「实例管理 → 脚本管理 → 获取脚本插件」里直接安装。也可以手动导入：

  1. 下载模块，保留原文件名。
  2. 在启动器的「实例管理 → 脚本管理」中，点击「＋」导入模块。若同名文件已存在，请先检查脚本库里的旧副本；导入时自动加编号的文件需用实际文件名引用。
  3. 另建或打开你的主脚本，在顶部写 import，再调用模块里的函数。检查语法后，运行主脚本并确认所需权限。

导入文件不会执行代码。模块不能自行联网、安装游戏模组或新增底层游戏指令；模块里的函数沿用脚本运行器的权限检查。

可用插件

01 / 玩家状态 · v1.0

生存状态检查

读取血量和饱食度，返回是否达到脚本设定的门槛。适合在出发前检查，或者在状态太低时发出提示。

权限：game.read

import "ochre-survival-v1.ochre";
if (!ochre_survival_ready(12, 8)) {
    say("先恢复血量和饱食度");
}

两个参数依次是最低血量（12 表示 6 颗心）和最低饱食度（满值 20）。

02 / 世界读取 · v1.0

落脚点检查

检查某个坐标的落脚空间和支撑，并判断到那里的直线是否被挡住。适合在移动前筛选候选点。

权限：game.read

import "ochre-terrain-v1.ochre";
Vec3 feet = player.position;
print(ochre_terrain_check(feet));

可换成 16 格内、已加载区域的目标脚底坐标。直线无碰撞不代表沿途有地面，也不会让角色移动。

03 / 移动与建造 · v1.0

向前搭路

站在缺口紧邻的实心地面上，朝向对岸。插件按视线最接近的东西南北方向找落脚点，自动从背包选用足够的石头、圆石或木板等方块。

需要 0.3.0-alpha.7 或更新版本及新版桥接。权限：game.read、inventory.write、player.look、player.move、world.place。

import "ochre-bridge-forward-v1.ochre";
if (ochre_bridge_forward()) {
    say("已到达对岸");
}

限一至三格宽、两端同高的缺口。材料在主背包时，需留一个空的快捷栏格子。导航优先走已有地面；必要时才建桥。

编写自己的模块

把可复用的函数放进单独的 .ochre 文件，给函数名加上自己的前缀以避免冲突。模块顶部可以导入其他模块，函数外不要写直接执行的语句。分享时附上版本、调用示例和需要的权限。

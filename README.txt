Markdown 正文更新

将 app.js 和 vendor 整个文件夹上传到 GitHub 仓库根目录，覆盖同名文件并提交。
最终路径：app.js、vendor/marked.js、vendor/purify.js。
不需要改数据库，不需要修改 HTML。
后台正文支持 Markdown，新增预览正文与插入图片按钮。
图片通过网址插入，不会上传电脑里的本地文件。
项目详情和动态详情都支持 Markdown。原有纯文本继续显示，换行保留。
保留项目排序、项目搜索、动态时间线和每页30条。
